# EPUB 阅读器 UI 改造计划：清简留白

日期：2026-10-16。状态：核心代码已实现；可用环境检查通过，Windows 实机与最终视觉验收待完成。

工作分支：`feature/ui-minimal-reading`；起点：`work` / `4dd66bc`。

## 设计依据与目标

采用用户最新选定的第 2 张设计稿：[清简留白参考图](design/ui-minimal-reference.png)。它是设计参考，尚不是运行截图。实际图片为 1487 × 1058；实现时按布局比例和逻辑尺寸适配窗口，不把图片拉伸为界面。此计划完整替代第 1 版方案。

目标是让中文长文成为视觉中心：近白底色、炭黑正文、克制的蓝灰强调色和充分留白。主阅读状态收起目录，正文栏在整个阅读区域居中，章标题在正文栏内左对齐；顶部为轻量工具栏，底部为通栏进度与章节导航。继续在现有 Rust / egui 原生程序中实现，保持便携、离线和现有阅读操作。

## 首轮视觉规格

以下为实现起点，最终用 Windows 实际截图校准。尺寸使用 egui 逻辑点，随系统 DPI 缩放，不机械照搬设计图像素。

| 项目 | 建议值 |
| --- | --- |
| 正文底色 / 正文字色 | `#FAFAF8` / `#282A2B` |
| 按需展开的目录底色 / 次级文字 | `#F3F4F3` / `#626B73` |
| 强调色 / 当前章浅底 / 分隔线 | `#536C7B` / `#E7EDF0` / `#E2E5E7` |
| 界面字体 | 微软雅黑或 Segoe UI，14–16；顶部书名使用次级字号 |
| 新用户浅色预设正文 | 宋体 22，行距 1.8，段距约 20–24，最大宽度约 680 |
| 章节标题 | 正文栏内左对齐，约 36–40；上方小字书名、下方短分隔线 |
| 工具栏 / 底栏 | 约 60–64 / 64–76 高；底栏含进度滑轨和信息行 |
| 目录 | 默认收起；展开时约 240–260 宽，保留手动拖宽和保存 |
| 目录行 / 控件点击高度 | 约 36–40 / 至少 32 |
| 正文边缘 | 窄窗口左右至少约 24–32，宽屏保持约 680 的正文栏并增加两侧留白 |

选中、悬停、键盘焦点和禁用态均需可辨认；当前章同时用标记与底色表达。正文和普通控件文字以至少 4.5:1 对比度为验收目标。图标使用许可清楚的本地资源，例如 Phosphor Regular 的必要图标子集，并保留许可；图标旁保留文字标签，不依赖特殊 Unicode 字符能否显示。资源随程序携带，不在运行时下载。

## 实现中的具体处理

1. **系统标题栏。** 保留当前 Windows 原生标题栏及拖动、缩放和系统按钮。第 2 版设计稿仅展示应用内容；第一轮在原生标题栏下实现应用工具栏，避免为外观改动窗口显隐和拖拽行为。视觉对比时将系统标题栏与应用内容区域分别记录。
2. **正文字体独立。** `fonts.rs` 当前把选中的字体同时注册为全局比例字体。改为稳定的界面字体族、正文族和正文粗体族；排版选择只影响正文。继续读取系统字体并提供回退，不要求用户额外安装字体。
3. **章节标题。** 正文栏开头使用小字书名、左对齐章标题、短分隔线和留白。先检查当前章段落结构：开头已有标题则直接优化该标题，不重复插入；没有时才考虑回退标题。只装饰章首主标题，不给每个子标题重复添加书名。顶部居中的书名与作者来自书籍元数据，缺失时作合理回退。设计稿中的《呐喊》和鲁迅只是示例，不能硬编码到产品。
4. **阅读位置。** 目录宽度、字体和排版变化会触发布局重算。继续使用章节、段落和段内偏移作为恢复锚点；标题留白必须纳入布局行坐标，不能用额外覆盖绘制破坏定位。空闲帧不得因格式化或进度舍入反复跳转。
5. **全书进度。** 保留当前“章节等权 + 章内段落”的估算方式，不显示虚构页码。维持 `SliderClamping::Edits`；滑轨独占底栏上排，宽度由容器决定，下排变化的章节名和百分比不能挤动滑轨；首次/末次章节对应按钮置灰。下排三个区域独立布局，避免长章名把中央导航挤偏。
6. **设置兼容。** 已保存的字体、字号、行距、主题、自定义前景/背景色、目录开关和宽度继续有效。浅色主题、约 680 正文宽度和收起目录作为新用户初始值，不强制覆盖已有用户的主题或目录偏好。新的默认排版只作用于首次运行或主动“恢复默认排版”；恢复排版继续保留目录偏好、透明度、自动显隐和老板键。优先复用已有设置字段，确需新增时提供 serde 默认值和旧 JSON 迁移测试。
7. **目录语义。** 保持现有搜索、折叠和锚点跳转；当前选中仍按现有章节规则表达，不为了高亮样式新增未经验证的段落定位机制。长书名、长章节名提供截断或合理换行，全文通过悬停提示查看。
8. **三段式工具栏。** 品牌与打开入口在左，书名作者在可用空间内居中，操作组在右；长书名优先省略并提供悬停全文，不能与左右按钮重叠。较窄时隐藏居中的元数据，再将次要操作收入更多菜单。

## 小窗口与不同主题

- **标准窗口 1100 × 800：** 新用户默认无侧栏，正文约 680 宽并在整窗居中；主动打开目录时正文在剩余区域重排。
- **大窗口 1440 × 1024：** 在目录关闭状态对照第 2 版参考图，校准居中正文、左对齐标题、顶部书籍信息和底部三段式导航；正文保持最大宽度。
- **窄窗口约 500–760 宽：** 阅读时临时收起已打开的常驻目录；目录按钮打开临时面板，选择后关闭。该临时状态不覆盖用户保存的目录开关和宽度。
- **最小窗口 500 × 350：** 优先保留正文、打开文件和目录入口；次要工具放入更多菜单，设置可滚动，底栏使用紧凑布局。
- **沉浸模式：** 沿用现有 F10 和退出入口，正文重新居中；F4、Ctrl+G、Ctrl+,、F11、Esc 的行为需要一起回归。
- **白天、纸张、夜间、自定义颜色：** 用相同布局和控件体系适配，正文依旧读取用户设置，避免浅色界面在夜间成为亮色面板。

## 验证与交付

实施验证范围及结果见 [UI 实施记录](UI_IMPLEMENTATION.md)。以下为完整验收要求：

1. 在具备 Rust MSVC、Windows SDK 和系统字体的 Windows 环境执行 `cargo fmt --check`、`cargo test --locked`、`cargo build --release --locked`；执行既有 EPUB 与存储自检。仓库的 `.cargo/config.toml` 指向 Windows MSVC，当前云环境为 Linux，不能把 Linux 上无法运行 Windows 原生测试误报为通过。
2. 重点复用 `src/ui.rs` 已有的整界面阅读回归：滚动条拖动、全书进度跳转、空闲帧位置不变、字体重排、章末滚动、阅读位置恢复；增加目录开关前后定位、窄窗口临时目录、旧目录偏好保留和通栏滑轨交互的必要覆盖，不为颜色常量写镜像测试。
3. 手动走通打开/拖入书籍、多级目录搜索与锚点、首末章切换、排版调整、重启恢复、沉浸/全屏、透明度和老板键；确认快捷键、保存和无持续空闲重绘行为维持正常。
4. 在 Windows 以 1100 × 800、1440 × 1024、500 × 350 逻辑尺寸及 100% / 150% / 200% DPI 检查：长标题、空书、空搜索结果、图片章节、白天/纸张/夜间和自定义颜色。
5. 用相同内容、相同窗口和相同 UI 状态对照第 2 版设计稿；主验收截图关闭目录，另外补充目录打开、设置打开和夜间状态。可合法使用的长文样书用于视觉验收，现有 fixtures 用于功能回归；记录截图、偏差、修复结果和原生标题栏的既定差异。无法捕获真实 Windows 窗口时明确标记视觉验收阻塞，不能用编译成功代替视觉通过。

最终交付包括改造后的源码、可构建的 Windows 程序、必要回归结果和截图记录。当前已完成本分支的核心实现和可用环境验证；Git 提交和后续发布以分支记录为准。Windows x64 release exe 已交叉构建并检查；真实 Windows 运行与最终视觉验收仍待 Windows 环境完成，见 WINDOWS_BUILD.md。
